# Rust Language Reference - `ast-editor`

Templates and queries for **Rust** (`.rs`).

## Templates

`functions`, `classes` and `imports`, and two Rust has of its own: `traits` and
`impls`.

## Queries

- **Impls**: `(impl_item trait: (type_identifier) @trait)`
- **Functions**: `(function_item name: (identifier) @function)`
- **Structs**: `(struct_item name: (type_identifier) @struct)`
